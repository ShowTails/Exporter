ShowTails · Full Account Exporter

Extract all mapped account records from Glide for ShowTails Desktop migration

1 · Select Account

When a Row ID is supplied, the exporter retrieves the email from the Users table. Otherwise, it searches the Users table by email. For internal use, enter the customer email.

Access notice: This tool uses the direct Glide API token in browser code, as requested. The Row ID and email are not authentication. Anyone who can access this tool and token may retrieve account data. Use only in an administrator-controlled setting.

Add more table mappings (JSON)

Paste a JSON array of table definitions with name, id, columns, and emailFields (logical column names). Optional relationFields identify rabbit-ID references. Example:

[{"name":"Litters","id":"native-table-...","columns":{"ownerEmail":{"type":"email-address","name":"..."},"doeId":{"type":"string","name":"..."}},"emailFields":["ownerEmail"],"relationFields":["doeId"]}]

3 · Export Settings

Exports are compressed and encrypted automatically into a password-free .showtails file. Image and attachment URLs are preserved; actual media bytes are not downloaded in this test version. Keep this internal administrator tool private.
